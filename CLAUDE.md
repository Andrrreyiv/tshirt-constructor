# tshirt-constructor — конструктор футболок

Статус-хендофф. Обновлено: 2026-07-23. Self-contained контекст для любой сессии/аккаунта.

## Что это
Онлайн-конструктор футболок (vanilla JS, без сборки): выбор типа (базовая/оверсайз), плотности, цвета, стороны (перёд/спина), загрузка принта в рамку с ценой по размеру в см, текст, итог заказа.

⚠️ НЕ ПУТАТЬ с `jetron-constructor` (конструктор ФУТБОЛЬНОЙ ФОРМЫ, линейки Champion/Legend). Тот же заказчик (jetronsport.ru), но это отдельный продукт и отдельное репо. Линеек здесь НЕТ: каждая футболка будет привязана к конкретной карточке товара WooCommerce.

## Где что
- Демо: https://andrrreyiv.github.io/tshirt-constructor/ (GitHub Pages, деплой = push в main)
- Конфиг и ценовое ядро: `src/config/tshirt-mock-config.json` — решения заказчика записаны в `_note`-полях с датами
- Код: `src/js/tshirt/{StepPrice,OrderBuilder,PrintEditor,...}.js`, UI: `src/js/ui/TshirtApp.js`
- Тесты: `node --test tests/*.test.js` (именно с глобом; npm-скрипта test нет). Сейчас 33/33
- `docs/` в .gitignore СОЗНАТЕЛЬНО (внутренние материалы) — журнал вопросов `docs/ОТКРЫТЫЕ-ВОПРОСЫ.md` живёт только локально

## Ценообразование (состояние 23.07)
- ГЛАВНОЕ: на боевом сайте цена САМОГО ИЗДЕЛИЯ подтягивается из карточки товара. Матрица в конфиге (base 180=600 / oversize 200=800 / 240=1000) — демо-заглушка. Детская = взрослая.
- Печать: ступенчатая (rule=min-containing), два метода с переключателем в UI — DTF (до 40×40=1050, 40×50=1250) и плёнка (до 30×40=700, 40×50=800). Возраст влияет на рамку: adult 40×50, child 30×40.
- Текст: standalone 500 (placeholder, ждёт подтверждения), при принте скидка 50% (не показывать явно).
- Цвета старта: белый, чёрный, слоновая кость (ivory подтверждена 23.07, pending снят).

## Открытые хвосты
1. Цена текста без принта — placeholder 500, подтвердить.

3. Интеграция на jetronsport.ru — платформа подтверждена (WooCommerce), доступ и встраивание позже.

## Грабли
- Edit/Write-инструменты иногда падают с `Not logged in` на файлах проекта → обход: node-скрипт точечных замен через Bash (однострочные якоря + `includes`-проверка).
- Кириллический вывод в консоли ломается → `PYTHONIOENCODING=utf-8` и/или вывод в файл.
